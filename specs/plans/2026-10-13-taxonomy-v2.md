# Taxonomy v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the flat venue list into a taxonomy where one capability tree classifies both venues and MCP tools, and let an agent connected to this server ask `find_capability` which venues and which MCP tools can do something.

**Architecture:** Three JSON record sets under `taxonomy/` — `capabilities.json` (the tree), `venues/*.json`, `mcps/*.json` — loaded and cross-checked by `src/taxonomy/`. A pure `findCapability` joins them and ranks agent paths. This server and its wallet server are entries in their own registry, and a test keeps each entry equal to the tools the server really registers.

**Tech Stack:** TypeScript (NodeNext ESM), zod v4, `@modelcontextprotocol/sdk` v1, vitest, dependency-free Node `.mjs` scripts, GitHub Actions.

**Spec:** `specs/taxonomy-v2.md`

## Global Constraints

- Node `>=20`. ESM only; relative TS imports end in `.js`.
- No new dependencies.
- Capability ids are exactly two lowercase levels: `/^[a-z][a-z_]*\.[a-z][a-z_]*$/`.
- `effect` is one of `read | unsigned_tx | signs`; `auth` is one of `none | api_key | oauth`.
- Venue records, MCP records, MCP tools and connect entries are strict: unknown fields are errors.
- MCP ids of this repo: `cardano-defi-mcp` (keyless) and `cardano-defi-mcp-wallet` (signing).
- Meta tools (never classified): `list_venues`, `get_venue`, `list_capabilities`, `find_capability`, `get_mcp`, `wallet_status`, `setup_wallet`, `configure`.
- This server never proxies a third-party MCP server.
- Commit messages follow the repo style (`feat: …`, `docs: …`, `ci: …`) and carry **no** `Co-Authored-By` trailer.
- `scripts/validate-taxonomy.mjs` stays dependency-free (Node built-ins only).

## Review Focus

1. A community venue PR that still carries the v1 `integration` field or a v1 capability like `"borrow"` — expected: rejected with the file name and the field, not silently stripped. (Task 2 loader test, Task 5 validator test.)
2. An MCP entry whose tool names a venue id with a typo — expected: load fails, naming the file, tool and venue. (Task 3 test, Task 5 validator test.)
3. An agent passing `"  LEND.Borrow "` or a bare group `"lend"` — expected: same result as `lend.borrow` / all `lend.*`; an unknown or partial id like `lend.b` errors and lists the valid groups rather than returning an empty success. (Task 4 tests; prefix rule in Task 1 test.)
4. A developer adds a tool to `src/tools/` or `src/wallet/tools.ts` without classifying it — expected: the test suite fails. (Task 3 self-consistency test.)
5. `find_capability` with a `venue` id that does not exist — expected: an error naming the id, not an empty result that reads like "nothing can do this". (Task 4 test.)

import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { z } from 'zod';
import {
  CapabilityNodeSchema,
  VenueSchema,
  type Capability,
  type CapabilityNode,
  type Category,
  type Venue,
} from './schema.js';

export * from './schema.js';

// src/taxonomy/ and dist/taxonomy/ are both one level below the repo root.
export const TAXONOMY_ROOT = fileURLToPath(new URL('../../taxonomy', import.meta.url));

export interface VenueFilter {
  category?: Category;
  asset?: string;
  capability?: Capability;
}

function readJson(path: string, label: string): unknown {
  try {
    return JSON.parse(readFileSync(path, 'utf8'));
  } catch (err) {
    throw new Error(`Invalid ${label}: not valid JSON (${(err as Error).message})`);
  }
}

function parseOrThrow<T>(schema: z.ZodType<T>, raw: unknown, label: string): T {
  const result = schema.safeParse(raw);
  if (!result.success) {
    const issues = result.error.issues
      .map((i) => `${i.path.join('.') || '<root>'}: ${i.message}`)
      .join('; ');
    throw new Error(`Invalid ${label}: ${issues}`);
  }
  return result.data;
}

/** Every `<dir>/*.json`, sorted by filename and schema-checked. */
function readRecords<T>(dir: string, schema: z.ZodType<T>, kind: string): Array<{ file: string; record: T }> {
  return readdirSync(dir)
    .filter((f) => f.endsWith('.json'))
    .sort()
    .map((file) => {
      const label = `${kind} file ${file}`;
      return { file, record: parseOrThrow(schema, readJson(join(dir, file), label), label) };
    });
}

export function loadCapabilities(root = TAXONOMY_ROOT): CapabilityNode[] {
  const label = 'capabilities.json';
  const nodes = parseOrThrow(z.array(CapabilityNodeSchema), readJson(join(root, label), label), label);
  const seen = new Set<string>();
  for (const node of nodes) {
    if (seen.has(node.id)) throw new Error(`Invalid capabilities.json: duplicate id '${node.id}'`);
    seen.add(node.id);
  }
  return nodes;
}

/** True when `id` is `query` itself or sits under the group `query` ("lend" matches "lend.borrow"). */
export function matchesCapability(id: string, query: string): boolean {
  return id === query || id.startsWith(`${query}.`);
}

export function loadVenues(root = TAXONOMY_ROOT): Venue[] {
  return readRecords(join(root, 'venues'), VenueSchema, 'venue').map(({ record }) => record);
}
```

export function loadVenues(root = TAXONOMY_ROOT): Venue[] {
  const known = new Set(loadCapabilities(root).map((c) => c.id));
  return readRecords(join(root, 'venues'), VenueSchema, 'venue').map(({ file, record }) => {
    const unknown = record.capabilities.filter((c) => !known.has(c));
    if (unknown.length > 0) {
      throw new Error(
        `Invalid venue file ${file}: ${unknown.map((c) => `'${c}'`).join(', ')} not in capabilities.json`,
      );
    }
    return record;
  });
}

export function listVenues(filter?: VenueFilter, root = TAXONOMY_ROOT): Venue[] {
  let venues = loadVenues(root);
  if (!filter) return venues;

  if (filter.category) {
    venues = venues.filter((v) => v.category === filter.category);
  }
  if (filter.asset) {
    const asset = filter.asset.toLowerCase();
    venues = venues.filter((v) => v.assets.some((a) => a.toLowerCase() === asset));
  }
  if (filter.capability) {
    const query = filter.capability.trim().toLowerCase();
    venues = venues.filter((v) => v.capabilities.some((c) => matchesCapability(c, query)));
  }
  return venues;
}

export function getVenue(id: string, root = TAXONOMY_ROOT): Venue | undefined {
  return loadVenues(root).find((v) => v.id === id);
}

export function searchVenues(q: string, root = TAXONOMY_ROOT): Venue[] {
  const needle = q.trim().toLowerCase();
  if (!needle) return [];

  return loadVenues(root).filter((v) =>
    [v.id, v.name, v.description, ...v.assets].some((field) =>
      field.toLowerCase().includes(needle),
    ),
  );
}

export function loadMcps(root = TAXONOMY_ROOT): Mcp[] {
  const capabilities = new Set(loadCapabilities(root).map((c) => c.id));
  const venues = new Set(loadVenues(root).map((v) => v.id));

  return readRecords(join(root, 'mcps'), McpSchema, 'MCP').map(({ file, record }) => {
    const problems: string[] = [];
    const names = new Set<string>();
    for (const tool of record.tools) {
      if (names.has(tool.name)) problems.push(`duplicate tool '${tool.name}'`);
      names.add(tool.name);
      if (!capabilities.has(tool.capability)) {
        problems.push(`tool '${tool.name}' capability '${tool.capability}' not in capabilities.json`);
      }
      for (const v of tool.venues ?? []) {
        if (!venues.has(v)) problems.push(`tool '${tool.name}' venue '${v}' is not a venue id`);
      }
    }
    if (problems.length > 0) throw new Error(`Invalid MCP file ${file}: ${problems.join('; ')}`);
    return record;
  });
}

export function getMcp(id: string, root = TAXONOMY_ROOT): Mcp | undefined {
  return loadMcps(root).find((m) => m.id === id);

/**
 * Joins the three record sets into the answer an agent needs: which venues
 * offer a capability, which MCP tools can do it there, and where nothing can.
 */

import {
  TAXONOMY_ROOT,
  getVenue,
  listVenues,
  loadCapabilities,
  loadMcps,
  loadVenues,
  matchesCapability,
} from './index.js';
import type { CapabilityNode, Effect } from './schema.js';

export interface FindQuery {
  capability: string;
  asset?: string;
  venue?: string;
}

export interface AgentPath {
  capability: string;
  /** null for a venue-agnostic tool (a wallet, or an aggregator that names no venues). */
  venue: string | null;
  mcp: string;
  tool: string;
  effect: Effect;
  official: boolean;
  /** Callable on the server the agent is already connected to. */
  here: boolean;
}

export interface Gap {
  venue: string;
  capability: string;
}

export interface FindResult {
  capability: string;
  venues: Array<{ id: string; name: string; capabilities: string[]; assets: string[] }>;
  paths: AgentPath[];
  gaps: Gap[];
}

export interface CapabilitySummary extends CapabilityNode {
  venues: number;
  tools: number;
}

const EFFECT_RANK: Record<Effect, number> = { read: 0, unsigned_tx: 1, signs: 2 };

// Callable now beats needs-install; holding no keys beats signing; the venue's own team beats a third party.
function comparePaths(a: AgentPath, b: AgentPath): number {
  return (
    Number(b.here) - Number(a.here) ||
    EFFECT_RANK[a.effect] - EFFECT_RANK[b.effect] ||
    Number(b.official) - Number(a.official) ||
    a.mcp.localeCompare(b.mcp) ||
    a.tool.localeCompare(b.tool) ||
    (a.venue ?? '').localeCompare(b.venue ?? '')
  );
}

export function findCapability(query: FindQuery, here: readonly string[], root = TAXONOMY_ROOT): FindResult {
  const capability = query.capability.trim().toLowerCase();
  const nodes = loadCapabilities(root);
  if (!nodes.some((n) => matchesCapability(n.id, capability))) {
    const groups = [...new Set(nodes.map((n) => n.id.split('.')[0]))];
    throw new Error(
      `Unknown capability '${query.capability}'. Pass a group (${groups.join(', ')}) ` +
        'or a capability id from list_capabilities.',
    );
  }
  if (query.venue && !getVenue(query.venue, root)) {
    throw new Error(`Unknown venue '${query.venue}'. Call list_venues to see the available ids.`);
  }

  const venues = listVenues({ capability, asset: query.asset }, root).filter(
    (v) => !query.venue || v.id === query.venue,
  );
  const venueIds = new Set(venues.map((v) => v.id));

  const paths: AgentPath[] = [];
  for (const server of loadMcps(root)) {
    for (const tool of server.tools) {
      if (!matchesCapability(tool.capability, capability)) continue;
      const base = {
        capability: tool.capability,
        mcp: server.id,
        tool: tool.name,
        effect: tool.effect,
        official: server.official,
        here: here.includes(server.id),
      };
      if (!tool.venues) {
        paths.push({ ...base, venue: null });
        continue;
      }
      for (const v of tool.venues) {
        if (venueIds.has(v)) paths.push({ ...base, venue: v });
      }
    }
  }
  paths.sort(comparePaths);

  const gaps = venues.flatMap((v) =>
    v.capabilities
      .filter((c) => matchesCapability(c, capability))
      .filter((c) => !paths.some((p) => p.venue === v.id && p.capability === c))
      .map((c) => ({ venue: v.id, capability: c })),
  );

  return {
    capability,
    venues: venues.map((v) => ({
      id: v.id,
      name: v.name,
      capabilities: v.capabilities.filter((c) => matchesCapability(c, capability)),
      assets: v.assets,
    })),
    paths,
    gaps,
  };
}

export function listCapabilities(root = TAXONOMY_ROOT): CapabilitySummary[] {
  const venues = loadVenues(root);
  const tools = loadMcps(root).flatMap((m) => m.tools);
  return loadCapabilities(root).map((node) => ({
    ...node,
    venues: venues.filter((v) => v.capabilities.includes(node.id)).length,
    tools: tools.filter((t) => t.capability === node.id).length,
  }));
}

// Fast, dependency-free check of taxonomy/ for PR feedback: the capability
// tree, venue records, MCP records, and the references between them. The zod
// schemas in src/taxonomy/schema.ts are the source of truth and are enforced
// by vitest; the rules below are duplicated on purpose so this runs with no
// install step and reports every problem with its filename. TAXONOMY_DIR
// points it at another tree, for tests.

import { readdir, readFile } from "node:fs/promises";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..");
const TAXONOMY = process.env.TAXONOMY_DIR ?? join(ROOT, "taxonomy");

const CATEGORIES = ["dex", "lending", "cdp", "stablecoin", "derivatives"];
const EFFECTS = ["read", "unsigned_tx", "signs"];
const AUTHS = ["none", "api_key", "oauth"];
const CAPABILITY_ID = /^[a-z][a-z_]*\.[a-z][a-z_]*$/;
const VENUE_FIELDS = ["id", "name", "category", "url", "description", "assets", "capabilities", "notes"];
const MCP_FIELDS = ["id", "name", "publisher", "official", "repo", "connect", "auth", "tools", "notes"];
const TOOL_FIELDS = ["name", "capability", "venues", "effect", "notes"];

const errors = [];
const fail = (where, message) => errors.push(`${where}: ${message}`);

const isNonEmptyString = (v) => typeof v === "string" && v.length > 0;
const isObject = (v) => v !== null && typeof v === "object" && !Array.isArray(v);
const isUrl = (v) => isNonEmptyString(v) && URL.canParse(v);

async function readJson(file) {
  try {
    return JSON.parse(await readFile(join(TAXONOMY, file), "utf8"));
  } catch (err) {
    fail(file, `could not read or parse JSON (${err.message})`);
    return undefined;
  }
}

/** Every <dir>/*.json that parses to an object, with filename/id and duplicate-id checks. */
async function readRecords(dir) {
  let names;
  try {
    names = (await readdir(join(TAXONOMY, dir))).filter((f) => f.endsWith(".json")).sort();
  } catch {
    fail(`${dir}/`, "directory is missing");
    return [];
  }

  const records = [];
  const seenIds = new Map();
  for (const name of names) {
    const file = `${dir}/${name}`;
    const record = await readJson(file);
    if (record === undefined) continue;
    if (!isObject(record)) {
      fail(file, "must be a JSON object");
      continue;
    }

    const expectedId = name.replace(/\.json$/, "");
    if (record.id !== expectedId) {
      fail(file, `"id" is ${JSON.stringify(record.id)} but the filename requires "${expectedId}"`);
    }
    if (isNonEmptyString(record.id)) {
      const first = seenIds.get(record.id);
      if (first) fail(file, `duplicate id "${record.id}", already used by ${first}`);
      else seenIds.set(record.id, file);
    }
    records.push({ file, record });
  }
  return records;
}

function checkFields(where, record, allowed) {
  for (const key of Object.keys(record)) {
    if (allowed.includes(key)) continue;
    const hint = key === "integration" ? " (removed in v2: agent access is now derived from taxonomy/mcps/)" : "";
    fail(where, `unknown field "${key}"${hint}`);
  }
}

function requireStrings(where, record, fields) {
  for (const field of fields) {
    if (!isNonEmptyString(record[field])) fail(where, `"${field}" must be a non-empty string`);
  }
}

function checkNotes(where, record) {
  if (record.notes !== undefined && !isNonEmptyString(record.notes)) {
    fail(where, '"notes", when present, must be a non-empty string');
  }
}

// --- capabilities.json -------------------------------------------------------

const capabilityIds = new Set();
const tree = await readJson("capabilities.json");
if (tree !== undefined && !Array.isArray(tree)) fail("capabilities.json", "must be a JSON array of capability nodes");

for (const [i, node] of (Array.isArray(tree) ? tree : []).entries()) {
  const where = `capabilities.json[${i}]`;
  if (!isObject(node)) {
    fail(where, "must be an object");
    continue;
  }
  checkFields(where, node, ["id", "label", "description"]);
  if (typeof node.id !== "string" || !CAPABILITY_ID.test(node.id)) {
    fail(where, `"id" must look like "group.action" in lowercase (got ${JSON.stringify(node.id)})`);
  } else if (capabilityIds.has(node.id)) {
    fail(where, `duplicate id "${node.id}"`);
  } else {
    capabilityIds.add(node.id);
  }
  requireStrings(where, node, ["label", "description"]);
}

function checkCapability(where, value) {
  if (!capabilityIds.has(value)) fail(where, `capability ${JSON.stringify(value)} is not a node in capabilities.json`);
}

// --- venues/ -----------------------------------------------------------------

const venues = await readRecords("venues");
if (venues.length === 0) fail("venues/", "no venue files found");
const venueIds = new Set(venues.map(({ record }) => record.id));

for (const { file, record: venue } of venues) {
  checkFields(file, venue, VENUE_FIELDS);
  requireStrings(file, venue, ["id", "name", "description"]);
  if (!isUrl(venue.url)) fail(file, `"url" must be a valid URL (got ${JSON.stringify(venue.url)})`);
  if (!CATEGORIES.includes(venue.category)) {
    fail(file, `"category" must be one of ${CATEGORIES.join(", ")} (got ${JSON.stringify(venue.category)})`);
  }
  if (!Array.isArray(venue.assets) || !venue.assets.every(isNonEmptyString)) {
    fail(file, '"assets" must be an array of non-empty strings');
  }
  if (!Array.isArray(venue.capabilities) || venue.capabilities.length === 0) {
    fail(file, '"capabilities" must be a non-empty array of capability ids');
  } else {
    for (const cap of venue.capabilities) checkCapability(file, cap);
  }
  checkNotes(file, venue);
}

// --- mcps/ -------------------------------------------------------------------

function checkConnect(where, entry) {
  if (!isObject(entry)) return fail(where, "must be an object");
  if (entry.transport === "stdio") {
    checkFields(where, entry, ["transport", "command", "args"]);
    if (!isNonEmptyString(entry.command)) fail(where, 'stdio needs a non-empty "command"');
    if (!Array.isArray(entry.args) || !entry.args.every((a) => typeof a === "string")) {
      fail(where, 'stdio needs "args" as an array of strings');
    }
  } else if (entry.transport === "http") {
    checkFields(where, entry, ["transport", "url"]);
    if (!isUrl(entry.url)) fail(where, 'http needs a valid "url"');
  } else {
    fail(where, `"transport" must be "stdio" or "http" (got ${JSON.stringify(entry.transport)})`);
  }
}

function checkTool(where, tool, seenNames) {
  if (!isObject(tool)) return fail(where, "must be an object");
  checkFields(where, tool, TOOL_FIELDS);
  if (!isNonEmptyString(tool.name)) fail(where, '"name" must be a non-empty string');
  else if (seenNames.has(tool.name)) fail(where, `duplicate tool name "${tool.name}"`);
  else seenNames.add(tool.name);
  checkCapability(where, tool.capability);
  if (!EFFECTS.includes(tool.effect)) {
    fail(where, `"effect" must be one of ${EFFECTS.join(", ")} (got ${JSON.stringify(tool.effect)})`);
  }
  if (tool.venues !== undefined) {
    if (!Array.isArray(tool.venues) || tool.venues.length === 0) {
      fail(where, '"venues", when present, must be a non-empty array (omit it for a venue-agnostic tool)');
    } else {
      for (const v of tool.venues) {
        if (!venueIds.has(v)) fail(where, `venue ${JSON.stringify(v)} is not a file in venues/`);
      }
    }
  }
  checkNotes(where, tool);
}

const mcps = await readRecords("mcps");

for (const { file, record: mcp } of mcps) {
  checkFields(file, mcp, MCP_FIELDS);
  requireStrings(file, mcp, ["id", "name", "publisher"]);
  if (typeof mcp.official !== "boolean") fail(file, '"official" must be true or false');
  if (!isUrl(mcp.repo)) fail(file, `"repo" must be a valid URL (got ${JSON.stringify(mcp.repo)})`);
  if (!AUTHS.includes(mcp.auth)) fail(file, `"auth" must be one of ${AUTHS.join(", ")} (got ${JSON.stringify(mcp.auth)})`);

  if (!Array.isArray(mcp.connect) || mcp.connect.length === 0) fail(file, '"connect" must be a non-empty array');
  else mcp.connect.forEach((entry, i) => checkConnect(`${file} connect[${i}]`, entry));

  if (!Array.isArray(mcp.tools) || mcp.tools.length === 0) {
    fail(file, '"tools" must be a non-empty array');
  } else {
    const seenNames = new Set();
    mcp.tools.forEach((tool, i) => checkTool(`${file} tools[${i}]`, tool, seenNames));
  }
  checkNotes(file, mcp);
}

if (errors.length > 0) {
  console.error(`${errors.length} problem(s) in taxonomy/:\n`);
  for (const e of errors) console.error(`  ${e}`);
  console.error("\nSchema: src/taxonomy/schema.ts");
  process.exit(1);
}

console.log(`${capabilityIds.size} capabilities, ${venues.length} venues, ${mcps.length} MCPs OK`);
```

        ? "external"

}

- [ ] **Step 1: Write the script**

`scripts/mcp-tools.mjs`:

```js
#!/usr/bin/env node
// Lists the tools an MCP server really exposes, by connecting and calling tools/list.
//
//   node scripts/mcp-tools.mjs --connect '{"transport":"http","url":"https://…/mcp"}'
//       print the server's tool names, one per line (for writing a taxonomy/mcps/ entry)
//   node scripts/mcp-tools.mjs --check [--out report.json]
//       for every taxonomy/mcps/ entry with auth "none" (except this repo's own,
//       which the unit tests cover), compare declared tools with the live list;
//       exit 1 if any declared tool is missing or a server cannot be reached
//
// It RUNS the server it connects to: stdio entries are spawned with their own
// command. Run it only where that is acceptable — a scratch machine, or a CI
// job with no secrets and no write permissions.

import { readdir, readFile, writeFile } from "node:fs/promises";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";
import { parseArgs } from "node:util";
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StdioClientTransport } from "@modelcontextprotocol/sdk/client/stdio.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..");
const MCP_DIR = join(ROOT, "taxonomy", "mcps");
const OWN_MCPS = ["cardano-defi-mcp", "cardano-defi-mcp-wallet"];

// Covers a free-tier cold start and a first `npx -y` install.
const TIMEOUT_MS = 120_000;

function withTimeout(promise, what) {
  let timer;
  const timeout = new Promise((_, reject) => {
    timer = setTimeout(() => reject(new Error(`${what} timed out after ${TIMEOUT_MS / 1000}s`)), TIMEOUT_MS);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

async function listTools(connect) {
  const transport =
    connect.transport === "stdio"
      ? new StdioClientTransport({ command: connect.command, args: connect.args, stderr: "ignore" })
      : new StreamableHTTPClientTransport(new URL(connect.url));
  const client = new Client({ name: "taxonomy-mcp-tools", version: "0.1.0" });
  try {
    await withTimeout(client.connect(transport), "connect");
    const names = [];
    let cursor;
    do {
      const page = await withTimeout(client.listTools(cursor ? { cursor } : undefined), "tools/list");
      names.push(...page.tools.map((t) => t.name));
      cursor = page.nextCursor;
    } while (cursor);
    return names.sort();
  } finally {
    await client.close().catch(() => {});
  }
}

async function check(out) {
  const files = (await readdir(MCP_DIR)).filter((f) => f.endsWith(".json")).sort();
  const entries = await Promise.all(files.map(async (f) => JSON.parse(await readFile(join(MCP_DIR, f), "utf8"))));
  const report = [];

  for (const mcp of entries) {
    if (mcp.auth !== "none" || OWN_MCPS.includes(mcp.id)) continue;
    // Prefer HTTP: it runs nothing locally.
    const connect = mcp.connect.find((c) => c.transport === "http") ?? mcp.connect[0];
    try {
      const live = new Set(await listTools(connect));
      const declared = mcp.tools.map((t) => t.name);
      const missing = declared.filter((n) => !live.has(n));
      const undeclared = [...live].filter((n) => !declared.includes(n));
      report.push({ id: mcp.id, ok: missing.length === 0, missing, undeclared });
    } catch (err) {
      report.push({ id: mcp.id, ok: false, error: err instanceof Error ? err.message : String(err) });
    }
  }

  for (const r of report) {
    const detail = r.error ?? (r.missing.length ? `missing: ${r.missing.join(", ")}` : "ok");
    console.log(`${r.ok ? "ok  " : "FAIL"} ${r.id} — ${detail}`);
  }
  if (out) await writeFile(out, JSON.stringify(report, null, 2));
  if (report.some((r) => !r.ok)) process.exit(1);
}

const { values } = parseArgs({
  options: { connect: { type: "string" }, check: { type: "boolean" }, out: { type: "string" } },
});

if (values.connect) {
  for (const name of await listTools(JSON.parse(values.connect))) console.log(name);
} else if (values.check) {
  await check(values.out);
} else {
  console.error("usage: mcp-tools.mjs --connect '<connect JSON>' | --check [--out <file>]");
  process.exit(2);
}
```

- [ ] **Step 1: Write the workflow**

`.github/workflows/mcp-drift.yml`:

```yaml
name: MCP drift

on:
  schedule:
    - cron: '0 6 * * 1'
  workflow_dispatch:

jobs:
  # Spawns third-party MCP servers, so it holds no write permissions and no
  # secrets. It only produces a report.
  check:
    runs-on: ubuntu-latest
    permissions:
      contents: read
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: node scripts/mcp-tools.mjs --check --out drift.json
        continue-on-error: true
      - uses: actions/upload-artifact@v4
        with:
          name: drift
          path: drift.json
          if-no-files-found: error

  # Never runs third-party code: it reads the report and files or updates one issue.
  report:
    needs: check
    runs-on: ubuntu-latest
    permissions:
      issues: write
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: drift
      - name: File or update the drift issue
        env:
          GH_TOKEN: ${{ github.token }}
          GH_REPO: ${{ github.repository }}
        run: |
          node -e '
            const fs = require("node:fs");
            const bad = JSON.parse(fs.readFileSync("drift.json", "utf8")).filter((r) => !r.ok);
            if (bad.length === 0) process.exit(0);
            const lines = bad.map((r) => r.error
              ? `- **${r.id}**: could not list tools (${r.error})`
              : `- **${r.id}**: declared but missing: ${r.missing.join(", ")}`);
            fs.writeFileSync("body.md",
              "The weekly tools/list check found taxonomy/mcps/ entries that no longer match their servers. " +
              "Fix the entry or remove it.\n\n" + lines.join("\n") + "\n");
          '
          if [ ! -f body.md ]; then echo "no drift"; exit 0; fi
          existing=$(gh issue list --state open --label mcp-drift --json number --jq '.[0].number')
          if [ -n "$existing" ]; then
            gh issue comment "$existing" --body-file body.md
          else
            gh label create mcp-drift --color D93F0B --description "A taxonomy MCP entry no longer matches its server" 2>/dev/null || true
            gh issue create --title "MCP drift: taxonomy entries out of date" --label mcp-drift --body-file body.md
          fi
```
